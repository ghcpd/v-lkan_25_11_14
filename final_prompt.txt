You are a web developer working inside a persistent code execution session.
Goal: Build a Flask-based frontend service called User Management Dashboard. Focus primarily on UI correctness, error states, and interaction flows, ensure the app runs successfully after each step.

1. Functional Requirements & API Design
Core Features:
Display a user list with pagination and sorting.
Support searching users by name or email.
Support adding new users (form: name, email, role).
Support editing existing user information.
Support deleting users (with confirmation dialog).
Support exporting user data to CSV/JSON files.
Error handling: when the backend API returns an error, display an error banner on the page.
2.Backend REST API (/api/users):
GET /api/users
Parameters: search, page, limit, sort_by, order.
Response: array of user objects (id, name, email, role).
POST /api/users
Request body: { "name": "...", "email": "...", "role": "..." }.
Response: the newly created user object.
PUT /api/users/<id>
Update user information.
DELETE /api/users/<id>
Delete the specified user.
Export
GET /api/users/export?format=csv/json → return a downloadable file.
Error Handling
Response format: {"error": "Invalid input"}.
The frontend page must show errors in a visible banner.
